# Asset provenance

## Original IKUN icon system

The file icons, chicken mark, suspenders pockets, jersey alphabet, basketball terminal, photo sticker, court and locker product glyphs were drawn as code-native vectors for this project. Distributed under the project MIT license. Sources: `scripts/build-icons.mjs` and `assets/product/`. `icons/ikun.woff` is generated by `scripts/build-product-font.py`. The extension PNG icon is rasterized from the same original vector mark.

No real-person photographs, recordings, songs, externally collected meme images, or generated anime illustrations are bundled in version 0.2.0.
